# FlightPlan — Claude handoff package

This contains the project specification, a full implementation prompt, your original Next.js file conventions, and 18 wireframe screenshots (PNG and editable SVG) plus overview sheets.

## How to use

1. Extract this ZIP into your intended project directory, preserving folder paths.
2. Open Claude Code (or an assistant with repository write and terminal access) at the project directory.
3. Paste the contents of `CLAUDE_BUILD_PROMPT.md` under **Copy/paste prompt**, or attach that file and ask Claude to follow it.
4. Claude should read `FLIGHTPLAN_IMPLEMENTATION_SPEC.md` plus `USER_FRONTEND_CONVENTIONS.txt` and inspect `wireframes/`.
5. Claude must implement the repo, then test the **single-start command** `docker compose up --build`.

The zip is a **handoff package**, not a runnable app yet. The compose configuration and application must be generated by Claude, as requested by the prompt. No real patient data or EHR credentials are included.

## Core constraints

- **Local email/password sign-in is first-class.** MyChart/Epic only optional external integrations.
- Next.js App Router and **no frontend `src` folder**.
- FastAPI / SQLAlchemy / PostgreSQL / Alembic / uv.
- Nested journeys with Level 1 → Level 2 → Level 3 → Level 4.
- Each of the 18 wireframes represented by a working app screen.
- Docker Compose builds, migrates, seeds, and launches everything automatically.

## Agent Teams

The build prompt explicitly requires **Claude Code Agent Teams**. Run from an interactive Claude Code session with Agent Teams enabled (`CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` in your environment or Claude settings) and provide the full build prompt to the team lead. Agent Teams is experimental; if unavailable, Claude should say so rather than claim it used a team.
